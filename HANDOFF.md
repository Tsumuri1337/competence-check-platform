# HANDOFF.md

## Что это за проект

Платформа проверки компетенций для российского рынка труда, основанная на
пяти действующих профессиональных стандартах Минтруда в области
информационной безопасности (группа 06). Кандидат на вакансию или
сотрудник компании проходит проверку по выбранному профстандарту в три
этапа — тест знаний, практическое задание, самооценка; ревьюер оценивает
практическое задание и видит сводный отчёт.

Этот проект — переработка прежнего PoC (HR background-check), от которого
остался только backend-скелет (Express + Postgres + миграции). Домен,
схема БД, все страницы и весь контент — новые.

## Легальная основа

Пять профстандартов (реестр Минтруда, группа 06) — коды, названия,
приказы и полная структура ОТФ/ТФ/знания-умения перечислены в
`backend/README.md`. При выборе состава профстандартов один из
изначально предполагавшихся вариантов (код 06.041, «Специалист по
обнаружению, предупреждению и ликвидации последствий компьютерных атак»)
оказался нереальным — фактический стандарт для этой профессии (12.004)
официально не публикуется, так как содержит сведения, составляющие
государственную тайну. Он заменён на 06.053.

**Важно:** контент всех пяти стандартов транскрибирован вручную из
официальных PDF (рендер страниц в изображения + визуальное чтение) — AI-
инструменты суммаризации веб-страниц галлюцинируют на этих документах
(проверено: один и тот же файл дал два взаимоисключающих фиктивных
результата через разные инструменты). Не доверяйте автоматическому
пересказу этих документов без проверки по первоисточнику.

## Что уже сделано

См. `backend/README.md` — полное описание стека, API, ролей и того, что
сознательно не реализовано в этом срезе. Коротко: полный банк вопросов
(один вопрос на каждый пункт знаний/умений) и заданий (одно на каждую
трудовую функцию) по всем пяти стандартам; каждая проверка получает
случайную выборку — 50 вопросов и 2 задания — с перемешанными вариантами
ответа; реальный вход ревьюера по email/паролю с сессией на httpOnly-куке.
