# Примеры

## `candidate-report-example.pdf` — полный отчёт ревьюера по кандидату

Экспорт панели ревьюера (`reviewer_dashboard.html`) для одной проверки —
вымышленный кандидат (ФИО, email и телефон ненастоящие), профстандарт 06.032.
Показывает все части отчёта в заполненном виде:

1. Шапка: кандидат, профстандарт, контакты, статус.
2. Итоговая оценка 0–100 с разложением: знания с учётом сложности, темп,
   практика, сертификаты; калибровка самооценки; «как считается».
3. AI-резюме — получено в ручном режиме через Gemini (кнопки «Скопировать
   запрос» / «Вставить ответ»): профиль, сильные и слабые стороны с
   доказательствами, рекомендации, настораживающие признаки.
4. Результат теста по темам требований.
5. Сертификаты и OSINT.
6. Практические задания: рубрика, ответ кандидата, AI-разбор полноты, оценка
   и комментарий ревьюера.
7. Самооценка по компетенциям и сводка.

AI-резюме сформировано до оценки практики ревьюером, поэтому в его тексте
упомянут предварительный балл 54 — итоговый после оценки ревьюера 57.
