# Концепция платформы (теоретический этап)

Пояснительная записка к целевому облику платформы. Программный код на этом этапе не меняется.

- `Концепция-платформы-проверки-компетенций.docx`: документ для редактирования (57 стр.; Times New Roman 14, интервал 1,5, абзацный отступ 1,25 см)
- `Концепция-платформы-проверки-компетенций.pdf`: та же записка в PDF

Содержание записки:
- анализ Положения об ОЦК;
- роли и права;
- модель проверки (разминка и ситуационные задачи);
- IDEF0 и DFD;
- схемы алгоритмов по ГОСТ 19.701-90;
- UML: варианты использования, последовательности, состояния, компоненты, развёртывание;
- ER-модель со словарём данных;
- макеты экранов;
- план реализации.

## Пересборка

`src/` содержит исходники рисунков (`diagrams/*.mmd` для Mermaid, SVG-генераторы в `custom-diagrams.js`) и сборщик документа.

```bash
cd docs/concept/src
npm install                      # mermaid, playwright; путь к Chromium можно задать в CHROMIUM
node render-mermaid.js           # diagrams/*.mmd → PNG
FS=17px NS=22 RS=22 node render-mermaid.js p-   # схемы ГОСТ 19.701, разбитые на две части
node custom-diagrams.js          # IDEF0, варианты использования, развёртывание
node wireframes.js               # макеты экранов (нужна папка wireframes/)
node build-docx.js               # out/*.docx
# номера страниц в содержании: docx → pdf (LibreOffice), python3 toc-pages.py, снова build-docx.js
```
